# Мета
Ознайомитися з основними принципами побудови професійних Python-проєктів відповідно до сучасних стандартів розробки (src-layout, pyproject.toml, анотації типів, модульність, контроль версій Git).

## Опис алгоритму (Варіант №3: Інтернет-магазин)
Для реалізації індивідуального Варіанта №3 «Інтернет-магазин» (Shop Manager) розроблено модульний застосунок:
1. **Моделі даних (`models.py`)**: дата-клас `Product`, що інкапсулює інформацію про товар (`name`, `category`, `price`, `quantity`) та обчислювану властивість `total_value`.
2. **Сервісний шар (`services.py`)**:
   - `calculate_inventory_value` — розрахунок сумарної вартості залишків на складі;
   - `find_product` — пошук товару за назвою (без урахування регістру);
   - `filter_by_category` — фільтрація списку товарів за категорією;
   - `find_most_expensive` — визначення найдорожчого товару в асортименті.
3. **Точка входу (`main.py`)**: демонстрація роботи з каталогом товарів.

## Висновок
У ході лабораторної роботи №2 створено повністю робочий пакет Python згідно зі стандартами PEP. Всі автотести та перевірки пройдено успішно.

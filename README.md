# Мета
Метою роботи є оволодіння навичками роботи зі структурами даних Python (list, tuple, set, dict, collections), декомпозиція програми на функції, використання функціональних особливостей мови (лямбда-функції, замикання, декоратори) та аналіз складності алгоритмів.

## Опис алгоритму (Варіант №3)
Для аналізу інтернет-магазину було реалізовано наступну логіку:
1. **Вибір структур даних**: `list` використано для зберігання списку товарів, `dict` для індексації за ID (забезпечує $O(1)$ для пошуку), `set` для виділення унікальних категорій, а `defaultdict` для ефективного групування за категоріями.
2. **Функціональна декомпозиція**: програма розділена на модулі (data, processors, analytics, main), що відповідають за окремі етапи обробки.
3. **Обробка даних**:
   - `list comprehension` застосовано для фільтрації товарів з низьким залишком.
   - `set comprehension` для швидкого збору категорій.
   - `lambda` для передачі ключа сортування та пошуку максимуму.
   - `closure` (замикання) `create_price_filter` дозволяє динамічно створювати фільтри за ціною.
   - `decorator` `@benchmark` використовується для вимірювання швидкості виконання ключових операцій.
4. **Складність**:
   - Пошук товару в `list`: $O(n)$.
   - Пошук товару через `dict index`: $O(1)$.
   - Сортування товарів: $O(n \log n)$.

## Висновок
У ході лабораторної роботи було успішно реалізовано систему аналізу даних інтернет-магазину. Використання професійних структур даних (зокрема, словників для індексації) дозволило суттєво оптимізувати операції пошуку порівняно з лінійним перебором. Завдяки функціональній декомпозиції, кодову базу легко підтримувати та масштабувати. Використання замикань та декораторів продемонструвало гнучкість Python у створенні інструментів з високим рівнем абстракції.
